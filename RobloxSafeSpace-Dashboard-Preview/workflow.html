Boundary ที่ต้องรักษา

  • Frontend ทำ UI, validation เบื้องต้น และนำเสนอผลตาม response
  • Backend ตรวจตัวตน/สิทธิ์/ข้อมูลจริงทุก request และบันทึก audit ตามนโยบาย
  • Database ถูกเข้าถึงผ่าน Backend เท่านั้น; browser ไม่มี database credentials
  • การส่งข้อความเข้า Roblox อยู่หลัง Backend และยังต้องยืนยัน delivery contract แยกต่างหาก
  • Request mutation ที่ timeout ไม่ถือว่าสำเร็จหรือไม่สำเร็จอัตโนมัติ ต้องตรวจสถานะก่อน retry
