Interaction contract

  • Loading: ปิด submit ซ้ำและแสดงสถานะรอ
  • Empty: แยกไม่มีข้อมูลจากโหลดล้มเหลว
  • Error: แจ้งข้อความที่เข้าใจได้ พร้อมลองใหม่
  • Destructive: ระบุเป้าหมายและผลกระทบก่อนยืนยัน
  • Dialog: native <dialog>, keyboard focus, Escape และ focus restoration
  • Permissions: แสดงเฉพาะข้อมูล/การกระทำที่ได้รับสิทธิ์ แต่ Server ต้องบังคับใช้จริง
  • Reduced motion: ปิด animation/transition ตามการตั้งค่าอุปกรณ์
